## 動手前必須知道的事

1. **所有會改資料的動作只能經過 `FlowService`。** 畫面不要直接 insert `LedgerEntry`／`Checkin`／`Redemption`。餘額沒有欄位，永遠由帳本加總。這次 UX 改版完全沒動 `FlowService`、`RewardEngine`、`TokenSigner` 和資料模型。
2. **SwiftData 的 `@Attribute(.unique)` 遇到重複是覆寫，不是報錯。** 要拒絕重複，必須在 `FlowService` 先查再寫。
3. **旅客端不放管理資訊**：不出現資料集編號、政策指標、獎勵公式、展示帳號。載客率數字只放在任務詳情的「旅綠幣怎麼算」展開區（附「示範資料」標籤）。管理端的模擬數字一律掛 `DemoBadge`。
4. **示範歷史以「重置當下」往回推 14 天產生。** 提早重置，展示當天圖表右側會空。**展示當天先重置。**
5. **資料只在單機。** 站牌碼可跨機掃；兌換／核銷必須同一支手機（QR 畫面下方有「切換到商家核銷」與「模擬店員掃描」）。
6. **兌換碼關掉畫面不會作廢**，5 分鐘後自然失效（期間點數保留）。這是為了單機展示能切到商家身分核銷。
7. **畫面上有金額或標籤的橫排**，大字級時要用 `AdaptiveStack` 改直排，否則會把整頁撐出螢幕。
8. UI 測試靠 `accessibilityIdentifier` 找按鈕（例如 `mission-primary-action`、`redeem-confirm`），改畫面時別刪。

## 常用操作速查

```bash
U=A0276595-0746-4C12-AA16-DCE868FD689E   # iPhone 17 Pro；其他：16e 6534B09A…、SE3 293AF525…、16 Plus 0D68A596…
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun simctl launch \
  --terminate-running-process $U com.thomaslin.islandflow2026 account=t-demo demo-progress=completed tab=2
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun simctl io $U screenshot out.png

# 大字級／深色模式
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun simctl ui $U content_size accessibility-extra-extra-extra-large
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun simctl ui $U appearance dark

# 直接查手機上的資料庫
CONT=$(DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcrun simctl get_app_container $U com.thomaslin.islandflow2026 data)
sqlite3 "$CONT/Library/Application Support/default.store" "SELECT ZUSERID, ZAMOUNT, ZREASON FROM ZLEDGERENTRY WHERE ZISSIMULATED = 0;"
```

注意：
- 模擬器沒開機時 `get_app_container` 會失敗，先 `xcrun simctl boot $U`
- **跑 `xcodebuild test` 會重裝 App，清掉模擬器上的資料**
- 改完字級記得改回：`content_size large`
- 三台測試用模擬器（`IF-iPhone-SE-3rd-generation`、`IF-iPhone-16e`、`IF-iPhone-16-Plus`）是 2026-09-26 建的

除錯旗標完整清單在 [README](../README.md#除錯旗標只在-debug-建置有效)。
