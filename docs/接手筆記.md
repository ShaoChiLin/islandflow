## 開發邊界

- 所有帳本、驗證與核銷寫入仍經 `FlowService`；保留獎勵鎖定、冪等核銷、圈存、到期與交易一致性。
- `RouteStop` 雖有 routeCode，但查詢仍多以站序處理；QR 路線固定 BTZ；加入紀錄唯一鍵尚無服務日期。
- `leave()` 有方法但無 UI、也尚缺所有權檢查；新增取消時一併處理，不只加按鈕。
- 舊資料庫打不開時會回退記憶體庫；不能用此 fallback 掩蓋新模型遷移失敗。
- 新版方針取代舊「旅客首頁移除全部模擬標籤」要求：保留精簡介面，但示範班次、預估舒適度、虛構店家都需可辨識。
- 月度人次／座位供給比不能直接證明班次超載，App 的單班載客率仍為模擬。
- 不新增正式套件、後端、多機同步、真實金流或公開發布；必要時先具體說明影響並取得確認。
- UI 的 accessibilityIdentifier 不刪；維持既有 34＋4 測試。只寫好方針不能移到功能已完成。

## 重跑方式

在 IslandFlow 目錄執行，destination 可換成可用模擬器；測試會重置測試環境的 App 資料，請用獨立模擬器。

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild \
  -project IslandFlow.xcodeproj -scheme IslandFlow \
  -destination 'platform=iOS Simulator,id=CC3834C3-B419-44A1-AAF4-8E1334BE31F0' \
  -parallel-testing-enabled NO test
python3 docs/audit-2026-09-29/check_routes.py
```

本次完整 xcresult 暫存於 `/tmp/IslandFlow-Audit-20260929.xcresult`；可長期保留的 log／截圖已在專案 docs。模擬器若關閉可先以 Xcode／Simulator 啟動。
